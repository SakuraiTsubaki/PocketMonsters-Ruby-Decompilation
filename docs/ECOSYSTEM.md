# Repository Ecosystem

This repository is the canonical home for work specific to its own game/project scope.

The broader repository ecosystem uses two aggregate views:

- **Sakurai** — research-control subset across the full repository ecosystem.
- **Tsubaki** — complete non-ROM superset across the full repository ecosystem.

The aggregate model covers Disassembly repositories, Decompilation repositories, and other project repositories. Aggregation must not create competing canonical ownership: this repository remains authoritative for its project-specific source and research, while aggregate repositories index, reference, synchronize eligible knowledge/artifacts as defined by their own role.

Complete ROM images are excluded from the aggregate corpus.
