# Roadmap

1. **Target definition** — identify releases, revisions, languages, regions, updates, hashes, and source provenance.
2. **Architecture census** — document executable, archive, filesystem, data, script, graphics, audio, and resource structures.
3. **Reproducible tooling** — create deterministic extraction, decoding, conversion, rebuilding, and validation tools.
4. **Source reconstruction** — replace opaque blobs with editable source/data where practical.
5. **Asset reconstruction** — preserve native identity and provenance while producing reviewable and insertion-ready material where required.
6. **Verification** — progress from observed to reproduced and matched results using hashes, round trips, and build checks.
7. **Coverage expansion** — add verified versions and domains without redesigning the repository root.

Roadmap phases may overlap, but repository-wide structure changes are not milestones.
